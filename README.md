# DevOps_Basic
Цель: Подготовить специалиста, который понимает жизненный цикл (CI/CD), умеет "упаковывать" любое приложение (Docker), запускать многосервисные приложения локально (Compose), конфигурировать серверы (Ansible) и развертывать отказоустойчивые системы в dev-test-production-подобной среде (Kubernetes).
